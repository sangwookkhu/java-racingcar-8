# java-racingcar-precourse

## 기능 목록

### Model

#### Car (자동차)
- [ ] 자동차 이름을 저장한다
- [ ] 자동차 이름이 5자 이하인지 검증한다
- [ ] 자동차 이름이 빈 문자열이 아닌지 검증한다
- [ ] 자동차의 현재 위치(전진 횟수)를 저장한다
- [ ] 무작위 값을 받아 4 이상이면 전진한다
- [ ] 현재 위치를 반환한다

#### Cars (자동차 목록)
- [ ] 여러 대의 자동차를 관리한다
- [ ] 쉼표(,)를 기준으로 자동차 이름을 분리한다
- [ ] 각 자동차 이름의 앞뒤 공백을 제거한다
- [ ] 빈 이름이 포함된 경우 예외를 발생시킨다
- [ ] 모든 자동차를 한 번씩 이동시킨다
- [ ] 가장 많이 전진한 자동차들을 찾는다 (우승자 판별)
- [ ] 우승자 목록을 반환한다

#### RacingGame (경주 게임)
- [ ] 자동차 목록을 저장한다
- [ ] 시도 횟수를 저장한다
- [ ] 시도 횟수가 1 이상인지 검증한다
- [ ] 주어진 횟수만큼 경주를 진행한다
- [ ] 각 라운드마다 모든 자동차를 이동시킨다
- [ ] 각 라운드의 결과를 수집한다

#### RandomNumberGenerator (난수 생성기)
- [ ] 0~9 사이의 무작위 값을 생성한다

### View

#### InputView (입력)
- [ ] 자동차 이름 입력 안내 메시지를 출력한다
- [ ] 자동차 이름을 입력받는다
- [ ] 시도 횟수 입력 안내 메시지를 출력한다
- [ ] 시도 횟수를 입력받는다
- [ ] 숫자가 아닌 값 입력 시 예외를 발생시킨다

#### OutputView (출력)
- [ ] 실행 결과 안내 문구를 출력한다
- [ ] 각 라운드의 자동차 상태를 출력한다 (형식: `이름 : ---`)
- [ ] 자동차 위치만큼 `-` 기호를 출력한다
- [ ] 라운드 사이에 빈 줄을 출력한다
- [ ] 최종 우승자를 출력한다
- [ ] 우승자가 여러 명인 경우 쉼표(,)로 구분하여 출력한다

### Controller

#### RacingController (게임 컨트롤러)
- [ ] 게임 전체 흐름을 제어한다
- [ ] InputView로부터 사용자 입력을 받는다
- [ ] 입력받은 데이터로 Model 객체를 생성한다
- [ ] 경주를 진행하고 각 라운드 결과를 OutputView로 전달한다
- [ ] 우승자를 판별하여 OutputView로 전달한다
- [ ] 예외 발생 시 애플리케이션을 종료한다

## 예외 처리

### 자동차 이름 입력 검증
- [ ] 빈 문자열 또는 공백만 입력한 경우 `IllegalArgumentException`
- [ ] 자동차 이름이 5자를 초과한 경우 `IllegalArgumentException`
- [ ] 빈 이름이 포함된 경우 `IllegalArgumentException` (예: "pobi,,jun")

### 시도 횟수 입력 검증
- [ ] 숫자가 아닌 값을 입력한 경우 `IllegalArgumentException`
- [ ] 1 미만의 숫자를 입력한 경우 `IllegalArgumentException`
